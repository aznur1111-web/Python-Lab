      Privacy and operation
      Lesson text, bookmarks, drafts, and progress stay in this browser. No account is needed. When you opt in and run code, the page downloads a pinned Pyodide runtime from jsDelivr and executes your source inside a Web Worker in this tab; it is not sent to a compiler server. First-run downloads can be large. A browser worker is an educational isolation layer, not a security boundary for hostile code, and desktop-only OS features may not work.
